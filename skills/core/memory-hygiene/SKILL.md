# 记忆写入判定

## 写入

- 用户明确表达长期偏好："以后默认…"、"我用中文"、"别给我表格"→ 写；
- 一次有结论的任务：任务 + 结论归档为情节（中间件自动完成）；
- 可复用做法：踩坑经验、流程约定 → 程序记忆。

## 不写

- 一次性表达："这次先用…"、"临时…" → 不写；
- 工具原始输出、日志、长表格 → 不写；
- 密钥、证件号、地址等敏感信息 → 不写；
- 模型自己推断出的"用户可能喜欢" → 不写。

## 冲突

- 同一 key 的新值让旧值失效，旧值保留有限历史；
- 置信度 1.0 的事实不会被更低置信度覆盖，需要覆盖时必须给出同样高的置信度与证据。

## 取用

- WARM 层偏好已常驻注入，不要每次都 read_memory 重复查；
- 只在"不确定用户以前说过什么"时检索 COLD。
