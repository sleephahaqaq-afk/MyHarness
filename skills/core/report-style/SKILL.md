# 报告输出规范

## 结构

1. **标题**：一句话说清主题与范围；
2. **摘要**：3 句话以内，给结论不给论证；
3. **正文**：按小标题组织，每段一个主张，段内先结论后依据；
4. **结论**：编号列出，每条可独立成立；
5. **下一步**：可执行动作，标明责任方或前置条件。

## 语气

- 用陈述句，不用"我觉得""可能大概"；
- 区分事实与推断：推断必须写明依据；
- 术语首次出现给一句解释，之后不再重复解释。

## 数据

- 数字带单位与口径（时间范围、样本量）；
- 来源写在句尾括号里，不堆在文末；
- 没有来源的数字不写。

## 长度

- 摘要 ≤ 3 句；正文按小标题分节，单节不超过 300 字；
- 详细数据放到表格或附件，不要放进正文长段落。
